号被封之前先备份。把这台电脑上 Claude Code 和 Codex 的聊天、记忆、Skill、指令、连接器收进一个压缩包。全在你的浏览器里处理，什么都不上传，不带登录凭证。

1
选 Claude 的文件夹

在你的用户目录里，叫 .claude。它是隐藏的：在选择窗口里按 ⌘ ⇧ . 就能看到（Windows 在 C:\Users\你\.claude）。

2
选 Codex 的文件夹

同一个地方，叫 .codex。没用 Codex 就跳过。

3
可选：选 .claude.json 文件

在用户目录里，和 .claude 文件夹挨着。里面是你连的 MCP 服务，选了才能列连接器清单。
